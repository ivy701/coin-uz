Asosiy manzil: https://stars.roxiy.uz/api/v1. Faqat HTTPS. Barcha endpointlar API kalitini talab qiladi. Kalitni serveringizda saqlang; brauzer yoki mobil ilova kodiga joylamang.

Buyurtma yaratish

POST/orders

Idempotency-Key majburiy: 8–128 ta lotin harfi, raqam yoki _ . : -. Namunalardagi username’ni haqiqiy qabul qiluvchiga almashtiring. max_price — eng ko‘p to‘lashga rozi bo‘lgan summa; narx bundan oshsa buyurtma qabul qilinmaydi.

curl https://stars.roxiy.uz/api/v1/orders \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: shop-order-10001" \
  -d '{"service":"stars","username":"recipient","amount":50,"max_price":"10000.00"}'

Stars uchun amount 50–100 000 oralig‘idagi butun son.

{"service":"premium","username":"recipient","months":3}

Premium uchun months faqat 3, 6 yoki 12.

{"service":"gift","username":"recipient","gift_id":"KATALOGDAGI_ID","note":"Tabriklayman!","anonymous":false}

gift_id qiymatini /gifts dan oling. note ixtiyoriy, ko‘pi bilan 30 belgi. anonymous ixtiyoriy, standart qiymati false.

{"service":"number","country":"KATALOGDAGI_KOD"}

country qiymatini /countries dan oling. Barcha so‘rovlar uchun ixtiyoriy max_price kiritish mumkin.

Summa buyurtma qabul qilinganda balansdan yechiladi. Bir xil kalit va ayni parametrlar bilan takrorlash eski buyurtmani qaytaradi (HTTP 200, replayed: true), yangi xarid yaratmaydi. Shu kalit bilan boshqa parametr yuborilsa 409 IDEMPOTENCY_CONFLICT qaytadi. API kalitini yangilash buyurtma takrorlanish himoyasini bekor qilmaydi.

Tarmoq uzilsa yoki javob kelmasa, o‘sha Idempotency-Key bilan qayta so‘rang. Yangi kalit yangi xaridni anglatadi. queued, processing yoki review holatida o‘sha mahsulotni qayta sotib olmang.

O‘zingizning bitta buyurtmangiz. Holatni kamida 5 soniya oralatib tekshiring.

curl "https://stars.roxiy.uz/api/v1/orders/$ORDER_ID" \
  -H "Authorization: Bearer $API_KEY"

GET/orders?page=1

API buyurtmalaringiz tarixi. Har sahifada ko‘pi bilan 20 ta. Bot yoki Mini App’da qilingan xaridlar bu ro‘yxatga kirmaydi.
