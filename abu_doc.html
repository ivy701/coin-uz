Stars, Premium, Gift API

Stars, Premium va Gift xizmatlarini o‘z botingiz yoki saytingizga ulang. So‘rovlar bizning API orqali qabul qilinadi, to‘lov bot balansingizdan yechiladi. Uchala xizmat buyurtmalari botning umumiy tarixida ko‘rinadi.

API barcha foydalanuvchilar uchun ochiq. Botda Hisobim → API yoki /api orqali shaxsiy kalitingizni oling. Barcha endpointlar, jumladan /pricing, API kalitini talab qiladi. To‘lov faqat o‘z bot balansingizdan yechiladi. Bloklangan hisoblar uchun cheklovlar saqlanadi.
Base URLhttps://stars.roxiy.uz/v2/apiX-API-KeyBotdagi /api bo‘limida yaratilgan shaxsiy kalit.

Kalitni faqat serverda saqlang. Namunalardagi $API_KEY o‘rnida o‘z kalitingiz ishlatiladi. Bearer autentifikatsiyasi ham qo‘llanadi. Narx va balanslar UZS / so‘mda.

Buyurtma yaratish

POST/stars/buy

curl -X POST 'https://stars.roxiy.uz/v2/api/stars/buy' \
  -H 'Content-Type: application/json' \
  -H "X-API-Key: $API_KEY" \
  -d '{"username":"recipient","amount":50,"order_id":"shop-order-1001"}'

username — qabul qiluvchi; amount — 50–100 000 oralig‘idagi butun son. Bu chegara xizmat provayderining amaldagi limitiga mos.

POST/premium/buy

curl -X POST 'https://stars.roxiy.uz/v2/api/premium/buy' \
  -H 'Content-Type: application/json' \
  -H "X-API-Key: $API_KEY" \
  -d '{"username":"recipient","duration":3,"order_id":"shop-order-1002"}'

duration — 3, 6 yoki 12 oy. Qabul qiluvchi username majburiy.

POST/gift/buy

curl -X POST 'https://stars.roxiy.uz/v2/api/gift/buy' \
  -H 'Content-Type: application/json' \
  -H "X-API-Key: $API_KEY" \
  -d '{"username":"recipient","gift_id":"KATALOGDAGI_GIFT_ID","note":"Tabriklayman!","anonymous":false,"order_id":"shop-gift-1001"}'

username va gift_id majburiy. gift_id qiymatini GET /gifts dan oling va qo‘shtirnoq ichida matn sifatida yuboring. note — ixtiyoriy tabrik, ko‘pi bilan 30 belgi; anonymous — ixtiyoriy true/false, standart qiymati false. Bir so‘rov bir dona gift yuboradi. Buyurtma javobida type:"gift" va gift_id qaytadi; holati GET /orders/{id} orqali kuzatiladi. Yakuniy webhookda ham gift_id keladi.

Ixtiyoriy parametrVazifasi
order_idO‘zingizning noyob buyurtma ID’ingiz, 1–128 baytli matn. Har TURLI xarid uchun boshqa ID; ayni xaridni takrorlashda ayni ID. Reseller/bot integratsiyalarida tavsiya etiladi.
callback_urlYakuniy holat yuboriladigan tashqi HTTPS manzil. 443-port, ochiq IPv4 DNS, maksimal 2048 belgi. Ichki IP, localhost, login/parolli URL va redirect ishlatilmaydi.
max_priceEng ko‘p to‘lashga rozi bo‘lgan summa, masalan "10000.00". Joriy narx yuqori bo‘lsa buyurtma qabul qilinmaydi.

order_id o‘rniga Idempotency-Key header ham ishlatish mumkin. Ikkalasi berilsa qiymatlari bir xil bo‘lsin. ID’siz bir xil username+miqdor so‘rovlari 90 soniya ichida yoki oldingi buyurtma hali ochiq bo‘lsa bitta buyurtma hisoblanadi. Turli mijozlarning bir xil xaridlarini ajratish uchun albatta noyob ID yuboring.

HTTP javobi yo‘qolsa ayni order_id bilan so‘rovni takrorlang. Yangi ID yangi xaridni anglatadi. Buyurtma ma’lum bo‘lsa GET /orders/{id} bilan holatini tekshiring.

Imzoni tekshirish

HMAC-SHA256 kaliti — xarid paytida ishlatilgan API kalitining kichik harfli SHA256 hex qiymati. Imzolanadigan matn: timestamp + "." + raw_body. Imzoni doimiy vaqtli taqqoslash bilan tekshiring, vaqt farqini 5 daqiqadan oshirmang va order_id bo‘yicha takroriy xabarlarni ajrating. API kaliti yangilansa, eski buyurtmalarning imzosi eski kalitga bog‘liq qoladi.

$signingKey = hash('sha256', $purchaseApiKey);
$expected = 'sha256=' . hash_hmac('sha256', $timestamp . '.' . $rawBody, $signingKey);
$valid = hash_equals($expected, $signature);

Webhook qo‘shimcha bildirishnoma. Muhim integratsiyalarda holatni GET /orders/{id} bilan ham tekshiring.

Nomer API va avvalgi versiya

https://stars.roxiy.uz/api/v1 avvalgidek ishlaydi. Virtual raqam/SMS uchun Nomer API qo‘llanmasi va v1 OpenAPI dan foydalaning. Stars, Premium va Gift endi shu v2 API ichida mavjud; avvalgi v1 integratsiyalari ham ishlashda davom etadi. Ikkala versiyada bir xil bot kaliti va balans ishlatiladi.
